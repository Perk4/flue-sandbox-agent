---
name: planning
description: Turn a goal into a sequenced plan Note. Use when the User wants a plan, a roadmap, or ordered next steps.
---

Follow this procedure for planning:

1. Read `PLAN.md`.
2. Write the plan as markdown from that template. Prefer a new Note over rewriting an unrelated one.
3. Create or update one Note with `upsertNote`. Omit `id` to create. Pass a known Note id only to update.
4. Keep the chat reply short. The Note holds the plan.
