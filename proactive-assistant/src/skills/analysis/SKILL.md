name: analysis
description: Turn a question or dump into a structured analysis Note. Use when the User wants analysis, a breakdown, or a written assessment.
---

Follow this procedure for analysis:

1. Read `ANALYSIS.md`.
2. Draft the Note body from that template. Stay in markdown.
3. Create or update one Note with `upsertNote`. Omit `id` to create. Pass a known Note id only to update.
4. Keep the chat reply short. The Note holds the analysis.
