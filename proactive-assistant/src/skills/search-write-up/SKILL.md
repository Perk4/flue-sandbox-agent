name: search-write-up
description: Write up search or research findings as one Note. Use when the User wants a search write-up, a literature note, or collected sources.
---

Follow this procedure for a search write-up:

1. Read `WRITEUP.md`.
2. Put sources and takeaways in that template. Do not cite chat turns as Notes.
3. Create or update one Note with `upsertNote`. Omit `id` to create. Pass a known Note id only to update.
4. Keep the chat reply short. The Note holds the write-up.
