---
name: task-tracking
description: Keep a task list as one markdown Note. Use when the User wants tasks, a checklist, or tracking open work.
---

Follow this procedure for task tracking:

1. Read `TASKS.md`.
2. Keep one Note for the list. Checkboxes are the tasks. Do not invent slugs as ids.
3. Create with `upsertNote` when the list is new. Update the known Note id when the list changes.
4. Keep the chat reply short. The Note holds the list.
